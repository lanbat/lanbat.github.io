# lanbat.github.io

Source for **[lanbat.github.io](https://lanbat.github.io/)**, the LAN BAT project hub.

A static page with no build step and no third-party requests. Edit `index.html` or
`assets/style.css` and push to `main`; GitHub Pages serves the repository root.

The nixconf deep-dive at [lanbat.github.io/nixconf](https://lanbat.github.io/nixconf/) lives in
[lanbat/nixconf/site](https://github.com/lanbat/nixconf/tree/master/site) and shares this page's
palette and type.
